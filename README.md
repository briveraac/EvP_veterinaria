# Veterinaria San Marcos — Sitio Web

Sitio web estático (HTML, CSS y JavaScript) para Veterinaria San Marcos (Rancagua, Chile).

> Estructura inicial del proyecto. El contenido, el resumen de información extraída del informe y el checklist de cumplimiento de la rúbrica se irán agregando en las próximas partes de la entrega.

## Cómo abrir el proyecto

Abre `index.html` directamente en un navegador, o sírvelo como archivos estáticos con cualquier servidor simple, por ejemplo:

```bash
npx serve .
```

## Archivos de referencia

- `informe.md` — informe de evaluación usado como insumo de contenido (no se muestra en el sitio).
- `rubrica.md` — rúbrica de evaluación con los criterios exigidos.
